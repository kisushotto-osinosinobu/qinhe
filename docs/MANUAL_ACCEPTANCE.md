# 本人手动验收与截图步骤

以下步骤供课程要求的“本人测试”使用。截图必须由你实际操作后获取；本项目自动化测试截图不能冒充本人操作。

## 准备

按 [Windows 从零运行](WINDOWS_SETUP.md) 启动 MySQL、后端和 Web。建议新建 `课程截图\01-登录`、`02-商品`、`03-库存`、`04-订单`、`05-小程序` 文件夹，并保留浏览器地址栏、系统时间或终端命令以增强可核查性。

## Web 建议截图点

1. PowerShell：`docker compose ps` 和 `/actuator/health` 返回 `UP`。
2. 登录页：错误密码提示；随后 `admin / Passw0rd!` 正确登录后的仪表盘。
3. 仪表盘：四项指标、近 7 日趋势、热销商品和低库存列表。
4. 商品分类：新增分类、编辑停用；创建关联商品后尝试删除分类并截取明确限制提示。
5. 商品：新增含编码/条码/图片的商品；重复编码或条码的错误提示；上下架后公开列表变化。
6. 供应商：新增、编辑、停用和分页查询；已被采购单引用时删除失败提示。
7. 采购：创建草稿、详情快照、确认入库；再次确认并核对库存没有二次增加。
8. 库存：当前/预占/可售解释；流水中的业务来源、操作人和时间；库存不足出库拒绝；盘点记录。
9. Web 收银：条码定位、购物清单、模拟收款成功；界面必须包含“不会发生真实资金交易”。
10. 销售订单：详情中的成交快照；待付款取消；收款；部分退货、全部退货与超额退货拒绝。
11. 系统管理：角色权限、用户状态修改、配置和审计日志。
12. CSV：导出本月订单并用文本编辑器或 Excel 打开，核对订单、退款和净额。

## 权限验收

分别登录四个演示账号并截图：

- `member` 看不到员工菜单；直接访问库存 URL 或调用接口返回 403。
- `cashier` 可以收银、收款、退货和导出，不能盘点或管理用户。
- `stock` 可以维护目录、采购和库存，不能管理用户或操作退货。
- `admin` 拥有全部管理权限。

再注册两个普通会员 A/B：A 下单后复制订单 ID，B 登录后直接访问该详情，截图 403；A 注销后使用浏览器后退或旧 Token 请求，截图 401。

## 双端同步验收

1. Web 修改商品名称、售价或库存。
2. 小程序页面下拉刷新，截图同一商品的新值。
3. 小程序会员加入购物车并提交订单，记录订单号。
4. Web 销售单刷新，截图同一订单号和 `MINIAPP` 来源。
5. Web 模拟收款，小程序订单页重新进入/下拉刷新，截图状态变更。
6. 对照 Web 库存流水截图预占、收款或取消对应记录。

## 微信开发者工具

构建后导入 `miniapp\dist\build\mp-weixin`。建议截图：项目导入信息、编译成功控制台、商品页、购物车、订单详情、个人中心、员工库存页及普通会员访问员工接口的失败提示。

真机截图需真实 AppID、HTTPS 合法域名和开发者账号。没有完成真机操作时，在论文中准确写“开发者工具构建/模拟器验证”，不得写“真机验证通过”或“已上线”。
